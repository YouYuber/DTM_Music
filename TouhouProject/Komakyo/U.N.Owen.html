  4. 使用楽器と詳細設定(GeneralUser GS)
    • Program #9 Room Kit (ドラム)
      • PC#9を選択して、もしバンクがあるなら｢Standard｣以外を選択。
      • スネア(D1/E1)のベロシティを110〜127程度に保つように設定。
      • DAW側でEQ(イコライザー)を3kHz〜5kHz付近で少しブーストさせ、低域の不要な溜まりをカットする。
      • リバーブレベルを37%程度に設定をロックする。(GeneralUser GS 2.0の場合)
      • 少し深めにリバーブをかけた後、ゲートで余韻を短く切る。
    • Program #10 GlockenSpile (鉄琴)
      • コーラス(CC#93)を30〜50程度にかけて横に広げる。(サンプラー又はDAWが対応している場合)
      • ベロシティを基本的に100〜120以上の高めに設定する。
      • リバーブ(CC#91)を80〜100とかなり深めに設定する。
      • 音源が対応している場合、Release(余韻)を少し短めに設定すると、連符を打った際に音が濁らない。
      • Program #9のシンバル音に埋もれやすいから、パン(CC#10)をセンターから少し左右どちらかに振る。
    • Program #12 Vibraphone (ビブラフォン)
      • デフォルトでも問題ないが、もしバンクがあるなら、より明るいトーンのバンクにする。
      • Cutoff Frequency(CC#74)を80〜100程度に上げ、高域を解放する。
      • Modulation(CC#1)を調整し、リバーブを深くして余韻で聴かせるようにする。
      • 中〜高域(C4以上)でメロディを弾く際は、ベロシティを110以上にする。
      • もし音が柔らかすぎると感じたら、Program #11 (Music Box)を音量を20%程度にして重ねる。
      • リバーブ(CC#91)は80〜100と深めにかける。
      • コーラス(CC#93)は20〜30程度にかけると、ステレオ感が増す。
    • Program #31 Distrotion Guiter (エレキギター)
      • ベロシティを120〜127の最大値付近で叩き込む。
      • ブライトネス(CC#74)は80〜90にして、高域のジリジリした成分を強調する。
      • レゾナンス(CC#71)は60〜70に上げると、特定の帯域が強調する。
      • ビブラート(CC#1)をかけたり、音が立ち上がりに一瞬下からベンドアップさせる。
      • 音と音の間を滑らかにつなぐポルタメント(CC#65 / CC#5)を有効し、ソロ楽器の存在感を出す。
      • EQ(イコライザー)を4kHZ付近を強めにブーストして、200Hz以下をカット。
      • コンプレッサーを深めにかけて音を平坦に潰す。
    • Program #37 Slap Bass 1 (ベースギター)
      • アクセントとなる音(裏拍やフレーズの終わり)のベロシティを120以上に設定する。
      • ベロシティを40〜60程度に落とした短い音を混ぜると、ZUN氏らしい疾走感が出る。
      • ブライトネス(CC#74)を80〜100程度に上げ、原画フレットに当たるような金属的な質感を強調する。
      • EQ(イコライザー)を200Hz付近を僅かにカットし、3kHz〜5kHz付近を軽くブーストする。
      • アタックタイムを10ms〜30msに設定したコンプレッサーをかけると、音の出だしが強調される。
    • Program #57 Trumpet (ZUNペット)
      • バンクはデフォルトでも問題はないが、｢Birght Trumpet｣等があったら、試しても良い。
      • ブライトネス(CC#74)を100〜120にすると、派手で硬い音になる。
      • レゾナンス(CC#71)を70〜80にすると、ZUNペットらしくなる。
      • アタックタイム(CC#73)を60前後(必要に応じて)にすると、吹きはじめのためが生まれる。
      • モジュレーション(CC#1)を音が伸びるタイミングで60〜90程度に一気に上げる。
      • ビブラート・レート(CC#76)を標準より少し速めの75〜85に設定する。
      • ビブラート・デプス(CC#77)を深め目の70〜80に設定する。
      • ベロシティは常に115〜127くらいにする。
      • ピッチベンドはフレーズなたまで、下から｢しゃくり上げる｣ようにベンドを入れる。
      • リバーブ(CC#91)は100前後とかなり深くかける。
      • DAWのEQ(イコライザー)は400Hz〜600Hz付近を少し削り、5kHz〜8kHz付近を持ち上げる。
    • Program #81 Square Wave (副シンセ)
      • レゾナンス(CC#71)を75〜90程度まで上げる。
      • ブライトネス(CC#74)を80〜100に設定する。レゾナンスと組み合わせる。
      • モジュレーション(CC#1)を50〜80まで上げる。
      • ポルタメント(CC#65 / CC#5)をONにし、タイムを少し短め(CC#5 = 40前後)に設定する。
      • もし音が細いと感じる場合は、同じトラックを複製し、片方のピットを数セントずらして重ねる。
      • リバーブ(CC#91)を80以上に設定する。
      • コーラス(CC#93)を40〜60に設定する。
    • Program #81 Square Wave (主シンセ)
      • 主シンセと副シンセは同じものを使用する。設定を変更して誤魔化す。
      • アタックタイム(CC#73)を65〜75程度に設定し、音の立ち上がりを僅かにマイルドにする。
      • Cutoff(CC#74)を60〜70付近で少し抑え、四角型波特有の角を取る。
      • レゾナンス(CC#71)をデフォルト値の64のまま、あるいは少し下げる。
      • ビブラート(CC#1)を20〜40程度で薄くかける。
      • リバーブ(CC#91)を90〜100と深めにかけて主役にする。
